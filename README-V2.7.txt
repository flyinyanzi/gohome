V2.7 – 客厅唱片机 + 全屋 BGM

- 去掉旧的可见虚线目标圈。
- 唱片拖进唱片机转盘中央的宽松隐藏区域即可自动放好。
- 唱针是隐藏热点：
  放好唱片后第一次点 -> 随机播放；
  播放中点 -> 暂停；
  暂停后点 -> 继续。
- 点已经放好的唱片 -> 拿走换下一张；下一次落针重新随机。
- 客厅右下角原图“播放清单”按钮接入播放器。
- 随机唱片和清单点播共享同一个全局 Audio、当前曲目和“正在播放”标记。
- 换房间不会中断音乐。
- 清单支持上一首 / 播放暂停 / 下一首 / 随机开关。
- 当前未内置 mp3。后续把文件放到 assets/audio/，并填写 js/music.js 顶部 PLAYLIST 即可。
- 缓存版本更新为 ?v=2.7。
