# 七夕小家 V1 原型

这是第一版可运行原型：
- 一个 HTML 应用承载玄关 + 家的总览 + 六个房间
- CSS / JS 分离
- 小纸条、愿望、梦境使用 IndexedDB 存在浏览器本机
- 书房保留技能五子棋 / 读心术入口
- 当前首页使用第一张统一手绘风视觉概念图
- 房间内先以交互骨架为主，下一步可逐间替换成独立手绘背景与透明物件素材

本地运行建议：
不要直接双击 index.html。用一个静态服务器启动，例如：
python3 -m http.server 8000
然后浏览器打开 http://localhost:8000/qixi_home_v1/

目录：
index.html
css/
js/
assets/images/
games/gomoku/
games/mind-reader/


## V1.1 客厅更新
- 客厅换成独立手绘背景
- 点击水杯：喝水反馈
- 点击落地灯：循环调节 4 档明暗
- 点击左下“慢一点”：显示/隐藏呼吸光圈
- 进入客厅 30 秒无操作：出现“这样待着也很好。”
- 唱片小游戏：把唱片拖到唱片机转盘中心；支持鼠标和触摸设备

这版先完成客厅的整体构图和主要动作，音乐、独立透明物件素材、多多真实形象会在后续继续精修。

## V1.3 手机适配与唱片交互
- 首页和客厅改为固定 1536×1024 的画布舞台，手机横屏会完整缩放到屏幕内，不再裁切。
- 右下角新增 − / ⌂ / ＋ 缩放控制；放大后可拖动画面。
- 手机支持双指缩放，横竖屏切换后自动重新适配。
- 背景和交互热点一起缩放，避免手机比例变化造成错位。
- 唱片改成唱片套 + 唱片 + 转盘轴心；摆放成功后提示圆框消失，只留下旋转唱片。
- 多多动作、窗外互动、小纸条和音乐播放清单留到后续。


## V1.4 画面适配修正
- 修正 V1.3 的核心缩放坐标问题：不再使用 `left:50% / top:50% + translate(-50%) + scale()`。
- 改为左上角原点 + JS 精确计算缩放后宽高，再居中放置整张 1536×1024 画布。
- 手机横屏、竖屏、桌面端默认都以“整张图完整可见”为基准，允许上下/左右留黑边，而不再裁图。
- 切换到首页/客厅时会重新 fit，避免隐藏页面初次计算尺寸不准确。
- Safari/手机地址栏变化通过 `visualViewport.resize` 重新适配。
- 桌面端鼠标滚轮可直接缩放；按钮和手机双指缩放继续保留。
- 所有热点都仍在同一个 1536×1024 舞台里，与背景一起做同一矩阵变换，避免缩放造成动作区域错位。


## V1.5 手机完整显示修正
- 现有插画是 1536×1024，也就是 3:2，不是 16:9。
- 手机端不再尝试“铺满屏幕”；改成真正的 contain/letterbox：四边完整显示优先，允许出现深色留边。
- 自动适配优先使用 `window.visualViewport`，避免 Safari 地址栏/工具栏导致计算出的可见区域比实际屏幕大。
- 默认完整显示时额外预留约 6% 安全边缘，防止浏览器功能条遮住图片边缘。
- 缩小下限从 1 放宽到 0.62，所以即使特殊手机比例仍可以继续把整张图缩小。
- 首页和客厅的背景与热点仍使用同一张 1536×1024 坐标画布，缩放后不会相互错位。
- 后续如果确定整套以手机横屏为主，可以重新绘制一套 16:9 房间素材；但这版先不重画，以免反复调整所有热点。


## V1.8 修正：不再叠两套按钮，卧室真正可交互
- 基于 V1.5 继续开发。
- 首页 `home-concept.png` 本身已经画有六个房间按钮，所以这版不再叠加第二套可见 HTML 按钮；HTML 只做透明点击热点，位置按原图 1536×1024 坐标逐个校准。
- 因此首页视觉上只会看到背景图自带的一套按钮，不再出现“双按钮”和明显错位。
- 卧室继续使用当前框架图，但把图上已经画好的“梦境抽屉 / 小纸条 / 窗外”做成真实热点。
- 床头实体灯增加 4 档明暗调节。
- 点击床铺附近的月亮热点会打开“睡不着的时候”卡片，并可启动 8 秒循环的呼吸光圈。
- 点击“梦境抽屉”会打开原有 IndexedDB 梦境记录/改写界面。
- 点击“小纸条”会打开卧室自己的本地存档纸条。
- 点击“窗外”会出现一张很轻的夜景提示卡。
- 下一阶段再重新绘制真正“无 UI 烘焙”的首页/卧室纯场景背景，到时把全部按钮彻底交给 HTML/CSS。
